# 📈 Personal Progress Tracker Bot

Асинхронный Telegram-бот для отслеживания личного прогресса. Позволяет создавать универсальные метрики (например, «Жим лежа, кг» или «Решенные олимпиадные задачи, шт.»), логировать данные и строить динамические графики в памяти.

## 🛠 Технологии и архитектура
* **Python 3.13**
* **Фреймворк:** aiogram 3.x (асинхронная обработка, FSM)
* **База данных:** SQLite + aiosqlite (асинхронные CRUD-запросы)
* **Аналитика:** matplotlib (рендеринг PNG графиков в `io.BytesIO`)
* **Фоновые задачи:** asyncio scheduler для рассылки напоминаний с учетом часового пояса пользователя.
